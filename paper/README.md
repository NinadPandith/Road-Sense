# Conference paper draft (W4)

IEEE conference format (`IEEEtran`). Build the PDF:

```bash
cd paper && make
```

Or upload `main.tex`, `refs.bib` and `figures/` to Overleaf. Red `[TBD: ...]` text marks every
number that comes from `ml/results/`; the confusion-matrix and failure-case figures appear
automatically once `ml/results/e3_confusion.png` and `ml/results/failure_grid.png` exist.

The draft is about 3 pages before results. Real results, the two figures, a qualitative-examples
figure and the discussion should bring it to 5–6 pages. Check your target conference's page limit
and template (most IEEE conferences use this class unchanged).
